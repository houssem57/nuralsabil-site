# Nur al Sabil · website

The public pages of the Nur al Sabil app, served by GitHub Pages at
<https://houssem57.github.io/nuralsabil-site/>.

- `privacy/` is the privacy policy (Arabic, English, German). Google Play links to it.
- `index.html` is a short page about the app.

The privacy policy's source is kept with the app's code; this repository holds the published copy. To change the policy, edit it there, copy it to `privacy/index.html` here, and push.
